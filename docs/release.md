# Как выпускать обновление

1. `npm test` — все тесты должны проходить.
2. Поднять `APP_VERSION` в `src/version.ts`, если изменение заметное для пользователя.
3. `npm run build` — проверить, что сборка чистая.
4. `git add -A && git commit -m "..." && git push`.
5. Через минуту обновление уедет на GitHub Pages.

## Что происходит на телефоне

- Service worker обновляется сам (`skipWaiting` + `clientsClaim`).
- Приложение один раз перезагружается и показывает «Обновлено до версии N».
- Журнал, машины и фото не трогаются: они в IndexedDB, а не в кэше.

## Если обновление «не приходит»

1. Открыть приложение, **полностью выгрузить** его из списка приложений.
2. Открыть заново — service worker проверит обновление при возврате в фокус.
3. Если не помогло: Настройки → «Проверить обновление».
4. Крайний случай: Настройки → «Сбросить кэш». Данные не потеряются, снесётся только кэш оболочки. Нужен интернет: после сброса приложение заново скачает оболочку.
